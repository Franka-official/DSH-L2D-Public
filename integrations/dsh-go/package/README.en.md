# DSH Go local bridge runtime

Run `node install.mjs --plan` and `node install.mjs --install` from the outer distribution directory. Reload the Go engine when prompted, then open DSH L2D Bridge (`DSH L2D桥接`) in Go settings. See the outer `README.en.md` for the full setup.
